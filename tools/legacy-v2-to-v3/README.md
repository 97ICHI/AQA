# Архив: как из AQA_Lab_v2.html получен v3

Это Python-скрипты, которыми версия 3.0 была получена из `AQA_Lab_v2.html` (перенос блоков, переразметка подсказок, правки CSS и JS). Они хранятся как история и **не нужны для обычной работы**: после разбиения на `src/` правки вносятся прямо в файлы `src/`, а сборку выполняет `node tools/build.mjs`.

Скрипты ссылаются на пути рабочей среды подготовки и без правки путей не запустятся. Исходный генератор версии 2 (в HTML упоминались `src/data/design.yaml` и тесты `tests/check_minisql.mjs`) в репозитории отсутствовал, поэтому `src/` восстановлен из собранного файла.
