# Структура курса

_Сгенерировано `node scripts/gen-structure.mjs` из `src/content/course.ts`. Не редактировать вручную._

Модулей: 11, уроков: 86, написано в новом формате: 1, заданий с автоматической проверкой: 4.

Маршруты: **С нуля** (start), **Уверенная практика** (practice), **Подготовка к Middle** (middle).
