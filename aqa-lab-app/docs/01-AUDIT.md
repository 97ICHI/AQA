## Что уже работает и сохраняется

- Полнота тем: тестирование и тест-дизайн, TypeScript, async, веб и HTTP, SQL, Git/Linux, Playwright (locators, assertions, fixtures, POM, сеть, трассировка), API и контракты, архитектура, изоляция, параллельность, отчёты, Docker, CI/CD, flaky, интервью.
- Технически выверенные главы (проверены в v3: actionability по исходникам, SQL на PostgreSQL, JS-примеры исполнены).
- Глоссарий A–Z, поиск, режим «Кратко», прогресс, тёмная/светлая тема, автономность одного файла.
- Учебный проект `aqa-lab-starter` (Node API + форма + настоящий Playwright, проверен в Docker и CI).

Ни одна глава v3 не удаляется: в приложении есть ссылка «Подробная глава» на соответствующий раздел v3 (файл поставляется вместе с приложением).

## Проблемы → изменения

| Проблема | Изменение | Польза | Как проверить |
| --- | --- | --- | --- |
| Главы по 10–17 минут с 10–19 разделами; новичок видит десятки терминов до первого результата | Модули из коротких уроков: одна основная идея, пример, «Попробуйте», разбор | Видимый результат через 5–10 минут | В каждом уроке ≤ 1 новой основной идеи; первый запуск теста — урок 1.2 |
| Первый же пример (`aqa-intro`) использует `async`, `{ page }`, locator, web-first assertion | Урок «Первый тест» честно разбирает каждую часть и отправляет к урокам, где она объясняется | Нет «магии», нет ложного понимания | Каждая конструкция примера имеет ссылку на урок |
| TypeScript — одна глава (15 разделов), затем сразу сложный тестовый код | 17 уроков JS → TS с запуском кода и разделением «ошибка типа / исключение» | Человек читает и пишет код теста | Каждый урок содержит исполняемый пример и задание с проверкой поведения |
| Интерактивы не различают «настоящее выполнение» и «модель» | Метка режима на каждом тренажёре: «Настоящее выполнение», «Учебная модель», «Записанный сценарий» | Нет иллюзии, что запускался Playwright | Метка отображается до запуска; тест e2e проверяет её наличие |
| SQL Playground — собственный движок MiniSQL (подмножество) | PGlite (PostgreSQL в WebAssembly), несколько наборов данных, сравнение по поведению | Настоящие ошибки PostgreSQL, нельзя «угадать» ответ | Задачи принимают эквивалентные запросы и отклоняют неверный JOIN на втором наборе |
| Python — справочная глава без практики | Отдельный маршрут: Pyodide в Web Worker, pytest внутри браузера | Практика без установки | Задания запускают настоящий pytest |
| Задания — в основном тесты с выбором ответа | Задания с проверкой поведения: функция на нескольких входах; тест ученика на исправной и сломанной версии | Проверяется навык, а не узнавание | Тест, который всегда проходит, отклоняется |
| Плотные подсказки, но без примера применения | Единый глоссарий с полями `example` и уроком; подсказка по hover, фокусу и касанию; Esc закрывает | Термин понятен в контексте | e2e: подсказка открывается клавиатурой и касанием |
| Графики (ROI, надёжность, оптимизация) — количественные модели с условными числами | Сохранены в v3 как углубление; в новых уроках — временные шкалы, таблицы и подсветка там, где они отвечают на вопрос | Меньше декоративных визуализаций | У каждого тренажёра записаны цель, параметр, наблюдение |
| Один длинный HTML (3 МБ) — нельзя подключить настоящие среды исполнения | Модульное приложение (Vite + React + TypeScript) с ленивой загрузкой сред | Реальные исполнители, при этом чтение работает без них | Сборка, e2e, проверка офлайн-матрицы |

## Интерактивы v3: что они на самом деле делают

| Тип | Интерактивы v3 | Режим |
| --- | --- | --- |
| Настоящее выполнение | SQL Playground (собственный движок MiniSQL, не PostgreSQL) | выполнение учебного движка |
| Учебная модель с реакцией на параметры | ROI, пирамида, BVA, таблица решений, надёжность набора, ожидания, оптимизация, параллельность, Docker Compose, pipeline, совместимость контрактов, валидатор схемы, конфигурация окружений | модель |
| Модель поверх реального DOM | Locator Playground (свой движок подмножества локаторов), перехват сети | модель |
| Записанный сценарий | Event Loop, отладчик, путь запроса, архитектура Playwright, порядок фикстур, trace, flaky-debugger, design timeline | заранее заданные состояния |

Ни один интерактив v3 не запускал настоящий Playwright или HTTP-запрос; v3 это указывал, но не на каждом тренажёре одинаково заметно.
