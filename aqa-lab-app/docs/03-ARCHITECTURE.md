# Этап 3. Архитектура

## Сравнение вариантов

| Критерий | A. Автономный HTML (v3) | B. Веб-приложение / PWA | C. B + локальный runner Playwright |
| --- | --- | --- | --- |
| Чтение без сети | Да, один файл | Да, после первой загрузки с HTTP-сервера; `file://` не поддерживается (модули, workers, WASM) | Как B |
| TypeScript: компиляция и запуск | Нет (только записанные примеры) | Да: компилятор TypeScript в Web Worker, запуск в отдельном Worker с остановкой | Как B |
| SQL | Учебный движок MiniSQL | PGlite (PostgreSQL в WASM) | Как B + PGlite внутри магазина |
| Python | Нет | Pyodide + pytest в Web Worker | Как B |
| Настоящий Playwright | Нет | Нет — только подписанные учебные модели | **Да**: тест ученика запускается настоящим Playwright против локального магазина |
| Объём | 3 МБ | ~2 МБ интерфейс + WASM по требованию (PGlite ≈ 9 МБ, Pyodide ≈ 14 МБ, TypeScript ≈ 9 МБ) | + Node.js, браузеры Playwright |
| Поддержка | Сложно: правки в огромных HTML-файлах | Уроки — Markdown, задания — данные + проверки | + сервер runner |
| Телефон | Чтение | Чтение и лёгкие задания; тяжёлые среды зависят от памяти устройства | Runner работает на компьютере |

## Решение

Основной формат — **B**, совместимый с **C**: приложение работает само по себе (чтение, TypeScript, SQL, Python, учебные модели), а если на компьютере запущен локальный runner (`npm run runner`), уроки Playwright запускают настоящие тесты. Без runner урок остаётся читаемым и честно сообщает, что исполнитель недоступен.

Стек: React 19 + TypeScript + Vite; CodeMirror 6; markdown-it для уроков; PGlite; Pyodide; IndexedDB не потребовалась — черновики и прогресс небольшие и хранятся в `localStorage` с экспортом и импортом JSON (выбор пересматривается, если черновики вырастут).

Почему React: компонентная модель удобна для тренажёров с состоянием; команда v3 уже пишет на TypeScript. Отдельный backend не добавляется: runner — один небольшой Node.js-процесс только для Playwright.

## Режимы исполнения (показываются на каждом тренажёре)

| Метка | Что происходит |
| --- | --- |
| **Настоящее выполнение** | Код ученика компилируется и исполняется (TypeScript в Worker, SQL в PGlite, Python в Pyodide, Playwright в runner). |
| **Учебная модель** | Код моделирует механизм (например, поиск элемента по роли на учебном DOM). Поддерживаемое подмножество подписано. |
| **Записанный сценарий** | Показ заранее подготовленных шагов (используется только в подробных главах v3). |

## Изоляция пользовательского кода

- **TypeScript.** Компиляция (`typescript` 5.9.3) и проверка типов — в Worker компилятора. Исполнение — в отдельном одноразовом Worker без доступа к DOM и `localStorage` приложения; `eval` в главном потоке не используется. Время ограничено (по умолчанию 3 с), кнопка «Остановить» и таймаут завершают Worker (`terminate()`), поэтому бесконечный цикл не блокирует интерфейс. Worker — изоляция от интерфейса, но **не защита от враждебного кода**: код выполняется с правами страницы в отдельном потоке и может делать сетевые запросы к тому же origin.
- **SQL.** PGlite в Worker; кнопка «Сбросить» пересоздаёт базу; задания проверяются на отдельных экземплярах базы.
- **Python.** Pyodide в Worker; остановка — `terminate()` и повторная загрузка среды (≈ 2–4 с).
- **Playwright (runner).** Локальный Node.js-сервер слушает только `127.0.0.1`, принимает запросы только с origin приложения, запускает один тест одновременно в отдельном временном каталоге с магазином на свободном порту, ограничивает время (60 с), завершает группу процессов, удаляет каталог. Это **учебный локальный инструмент для одного пользователя**: запуск чужого кода в нём не изолирован от вашей машины, Docker также не является полной защитой. Для многопользовательской версии нужна отдельная архитектура изоляции (контейнеры/VM на запуск, квоты, сеть только к учебным сервисам).

## Работа без сети

| Функция | После первой загрузки без сети |
| --- | --- |
| Чтение уроков, глоссарий, поиск, прогресс | Да |
| TypeScript-тренажёр | Да (компилятор — часть сборки) |
| SQL-тренажёр (PGlite) | Да (WASM — часть сборки) |
| Python-тренажёр (Pyodide + pytest) | Да (Pyodide и колёса pytest — часть сборки); сетевые библиотеки Python не поддерживаются |
| Playwright runner | Да, если runner и браузеры установлены заранее |
| Подробные главы v3 | Да (файл поставляется вместе с приложением) |

Сервис-воркер PWA не добавлен в первый выпуск: «после первой загрузки» означает работу через локальный `npm run preview`/статический сервер и кэш браузера. Браузер может очистить хранилище; экспорт прогресса — защита от потери.
