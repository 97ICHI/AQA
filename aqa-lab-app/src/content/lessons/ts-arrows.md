:::why
Первая строка любого теста Playwright — `test('…', async ({ page }) => { … })`. В ней три идеи сразу: стрелочная функция, функция, переданная в другую функцию, и «распаковка» объекта в параметрах. Разберём их по одной, и эта строка станет понятной.
:::

## Стрелочная функция

[[arrow-function|Стрелочная функция]] — короткая запись функции:

```ts tests/helpers/money.ts
// обычное объявление
function lineTotal(price: number, qty: number): number {
  return price * qty;
}

// то же самое стрелкой
const lineTotal2 = (price: number, qty: number): number => {
  return price * qty;
};

// если тело — одно выражение, фигурные скобки и return можно убрать
const lineTotal3 = (price: number, qty: number) => price * qty;
```

Слева от `=>` — параметры, справа — тело. Без фигурных скобок результат выражения возвращается автоматически. С фигурными скобками нужен явный `return`, иначе функция вернёт `undefined`.

## Callback: функция как значение

Функцию можно передать в другую функцию, как число или строку. Переданную функцию называют [[callback|callback]] («обратный вызов»): получатель сам решит, когда её вызвать.

Вы уже видели это в `filter` и `map`: `products.filter((p) => p.stock > 0)` — в `filter` передана функция, и `filter` вызывает её для каждого товара.

`test` устроен так же. Вы передаёте ему название и функцию-тело, а запускает её раннер — в нужный момент, с подготовленными данными:

```ts tests/cart.spec.ts
test('корзина пуста при входе', async ({ page }) => {
  // тело теста — callback; его вызовет Playwright Test
});
```

Callback — не обязательно «сразу». Функция `setTimeout(() => console.log('прошла секунда'), 1000)` вызовет переданную стрелку через секунду, а код после `setTimeout` выполнится сразу. Получатель решает не только *как*, но и *когда* вызвать callback. Эта идея пригодится в уроке про асинхронность: многое в тестах происходит «потом», и важно понимать, кто и когда вызывает ваш код.

Частая ошибка новичка — вызвать функцию вместо того, чтобы её передать: `setTimeout(showTotal(), 1000)` вызовет `showTotal` немедленно и передаст в `setTimeout` её *результат*. Передавать нужно саму функцию: `setTimeout(showTotal, 1000)` или стрелку `() => showTotal()`.

## Destructuring: достать поля в переменные

[[destructuring|Destructuring]] («деструктуризация», распаковка) достаёт значения из объекта или массива в отдельные переменные:

```ts tests/data/order.ts
const order = { id: 17, status: 'paid', total: 900 };

const { id, status } = order;          // id = 17, status = 'paid'
const [first, second] = ['Блокнот A5', 'Ручка'];   // first = 'Блокнот A5'
```

Распаковывать можно прямо в параметрах функции. Тогда функция получает объект, но сразу работает с его полями:

```ts tests/data/order.ts
const orderLabel = ({ id, status }: { id: number; status: string }) => `Заказ №${id}: ${status}`;
orderLabel(order);   // 'Заказ №17: paid'
```

Теперь строку теста можно прочитать целиком. Playwright вызывает тело теста и передаёт **один объект** с готовыми помощниками (fixtures): `page`, `request`, `context` и другими. Запись `({ page })` берёт из него только `page`. Слово `async` означает, что внутри будут ожидания — `await`; это тема отдельного урока.

:::

:::mistake Фигурные скобки без return
`items.map((i) => { i.price * i.qty })` вернёт массив из `undefined`: фигурные скобки означают «тело функции», а в нём нет `return`. Либо уберите скобки, либо добавьте `return`.
:::

:::deep Вернуть объект из стрелочной функции
`() => { id: 1 }` не возвращает объект: фигурные скобки читаются как тело функции. Объект нужно обернуть в круглые скобки: `() => ({ id: 1 })`. Так часто пишут генераторы тестовых данных.
:::

:::tech Стрелочные функции и this
Стрелочная функция не имеет собственного `this` — она берёт его из окружающего кода. Поэтому стрелки удобны как callbacks внутри методов класса. Методы самого класса обычно пишут обычной записью. Подробнее о `this` — в уроке про классы.
:::

:::interview
**Вопрос:** «Что означает `async ({ page }) => { … }` в тесте Playwright?» **Ответ по сути:** это асинхронная стрелочная функция — тело теста, переданное в `test` как callback. Раннер вызывает её и передаёт объект fixtures; destructuring `{ page }` достаёт из него страницу, изолированную для этого теста.
:::
