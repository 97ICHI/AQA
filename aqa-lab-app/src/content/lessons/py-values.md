## Значения и типы

Программа работает со **значениями**. У каждого значения есть тип, и тип определяет, что с ним можно делать.

| Тип | Пример | Что это |
|---|---|---|
| `int` | `390`, `-1`, `0` | целое число |
| `float` | `4990.0`, `0.1` | дробное число |
| `str` | `"Блокнот A5"`, `'paid'` | строка (текст) |
| `bool` | `True`, `False` | логическое значение |
| `NoneType` | `None` | «значения нет» |

Строки пишутся в кавычках — одинарных или двойных, разницы нет. `True`, `False` и `None` пишутся с большой буквы и без кавычек. `None` — аналог `null` в JSON и `NULL` в SQL: «значение отсутствует».

Узнать тип значения помогает функция `type()`: `type(390)` — `int`, `type("390")` — `str`.

## Переменные

Переменная — имя, которое ссылается на значение. Создаётся первым присваиванием, объявлять тип не нужно:

```py tests/data.py
title = "Блокнот A5"
price = 390
qty = 2
total = price * qty      # 780
in_stock = True
promo_code = None

print(title, total)       # Блокнот A5 780
```

Имена пишут в стиле `snake_case`: строчные буквы и подчёркивания (`order_id`, `cart_total`). Имя должно объяснять, что лежит внутри: `total` лучше, чем `t`.

Переменную можно переприсвоить, в том числе значением другого типа: Python это разрешит. Именно поэтому в тестах полезно проверять не только значение, но и тип: `"390"` и `390` выглядят одинаково при печати, но ведут себя по-разному.

## print и f-строки

`print()` выводит значения через пробел. Для понятного вывода удобны f-строки — строка с префиксом `f`, в которую подставляются выражения в фигурных скобках:

```py tests/report.py
order_id = 101
total = 5770
print(f"Заказ №{order_id}: {total} ₽")   # Заказ №101: 5770 ₽
```

## Сравнения и логика

Операторы сравнения возвращают `bool`: `==` (равно), `!=` (не равно), `<`, `<=`, `>`, `>=`. Логические операции — словами: `and`, `or`, `not`.

```py tests/rules.py
price = 390
stock = 0
can_buy = price > 0 and stock > 0     # False
is_free = price == 0                  # False
```

`=` — присваивание, `==` — сравнение. Путать их в Python сложно: `if price = 0:` — синтаксическая ошибка.

:::deep Динамическая и строгая типизация
Python *динамически* типизирован: тип хранится у значения, а не у переменной, и одной переменной можно присвоить сначала число, потом строку. Но он *строго* типизирован: `390 + "1"` — ошибка `TypeError`, а не `"3901"`, как в JavaScript. Для подсказок есть аннотации `price: int = 390` — интерпретатор их не проверяет, их читают редактор и утилиты вроде mypy.
:::

:::interview
**Вопрос:** «Какие базовые типы есть в Python и чем `None` отличается от `0` и `""`?» **Ответ по сути:** `int`, `float`, `str`, `bool`, `None` (плюс коллекции `list`, `dict`, `tuple`, `set`). `None` означает отсутствие значения, а `0` и `""` — конкретные значения. Все три «ложны» в условии `if`, поэтому для проверки на отсутствие пишут `is None`, а не `if not x`.
:::
