# AQA Lab — приложение

Интерактивный учебник и тренажёр по автоматизации тестирования. Наследник `AQA_Lab_v3.html` (полный текст v3 открывается из приложения офлайн).

## Как запустить приложение

### Шаг 1. Установить Node.js (один раз)

1. Откройте сайт **https://nodejs.org**.
2. Нажмите большую зелёную кнопку **LTS** — скачается установщик.
3. Запустите установщик и везде нажимайте **Next**, ничего не меняя.
4. Перезагрузите компьютер.

### Шаг 2. Скачать проект

1. Откройте в браузере страницу проекта:
   **https://github.com/97ICHI/AQA/tree/claude/aqa-lab-audit-improve-11emv5**
2. Нажмите зелёную кнопку **`<> Code`** справа вверху.
3. В выпавшем окне нажмите **Download ZIP**.
4. Найдите скачанный архив в папке «Загрузки», нажмите на него правой кнопкой мыши → **Извлечь всё…** → **Извлечь**.

### Шаг 3. Запустить

1. Откройте распакованную папку, затем папку **`aqa-lab-app`**.
2. Дважды щёлкните файл **`start-windows.bat`**.
3. Если появится синее окно «Windows защитила ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**.
4. Откроется чёрное окно. При первом запуске оно несколько минут скачивает нужные компоненты, затем браузер сам откроет приложение.

Если браузер не открылся сам — введите в адресной строке **http://localhost:4173**.

**Чёрное окно не закрывайте**, пока пользуетесь приложением: если его закрыть, приложение перестанет работать. В следующий раз снова дважды щёлкните `start-windows.bat` — запуск будет быстрее.

## Для разработчиков

```bash
cd aqa-lab-app
npm ci
npm run dev                         # http://localhost:5173, изменения видны сразу
npm run build && npm run preview    # http://localhost:4173, собранная версия
```

Для практики Playwright — локальный runner (в отдельном окне терминала):

```bash
npx playwright install chromium   # один раз
npm run runner                    # печатает токен; вставьте его на странице «О приложении»
```

## Что выполняется по-настоящему

| Тренажёр | Движок | Метка в интерфейсе |
|---|---|---|
| TypeScript | компилятор TypeScript 5.9 (strict) в Web Worker; код — в одноразовом Worker с таймаутом и «Остановить» | Настоящее выполнение |
| SQL | PostgreSQL 17 в WebAssembly (PGlite 0.5) в Web Worker; 3 набора данных | Настоящее выполнение |
| Python | CPython 3.14 (Pyodide) + pytest 9 из локальных пакетов, в Web Worker | Настоящее выполнение |
| Playwright | Playwright Test 1.58 через локальный runner и учебный магазин с управляемыми дефектами | Настоящее выполнение; без runner — «Записанный сценарий» |
| Лаборатория локаторов | упрощённая модель ролей и доступных имён | Учебная модель |

## Команды

| Команда | Что делает |
|---|---|
| `npm run test:content` | структура уроков, термины, виджеты, связи заданий |
| `npm run typecheck` | проверка типов приложения |
| `npm run build` | типы + сборка в `dist/` |
| `npm run test:e2e` | e2e интерфейса и самопроверка всех заданий: эталон проходит, стартовый код — нет (для заданий Playwright нужен runner и `AQA_RUNNER_TOKEN`) |
| `npm run import-glossary` | пересобрать `src/content/glossary.json` (v3 + дополнения) |
| `node scripts/gen-structure.mjs` | обновить `docs/02-STRUCTURE.md` |
| `node runner/shop.mjs [вариант]` | поднять учебный магазин вручную (варианты — в `runner/shop.mjs`) |
