## Выполненные изменения

- **Содержание.** Переписаны введение и «Первый запуск» (теперь это короткий маршрут и один рабочий цикл с реальным выводом падения), «Кратко» для окружения, практики и «Первого запуска». Все 17 блоков версии 2 перенесены в логику глав (якоря сохранены), частично слиты с соседним текстом: Event Loop в Node.js, определение safe/idempotent, дубль детерминированности между главами 22 и 24. Сведения о версиях, истории, проверках, ограничениях и источниках собраны в новой справочной главе «О учебнике». Оглавления глав и ссылки «Кратко» пересобраны, «глава N» стали ссылками.
- **Подсказки.** 1430 → 760: один термин один раз в разделе, только в обычном тексте (не в коде, заголовках, таблицах-шапках, ссылках, на метках кода). Исправлены все найденные искажения регистра. Подсказка открывается с клавиатуры, фокус переходит внутрь, `Esc` возвращает его на термин.
- **Дизайн.** Единые токены радиусов (3 ступени), палитра разделов без жёлтого и зелёного, свечение отключено, спокойные линии вместо градиентных украшений, фиолетово-голубые акценты в светлой теме и в демонстрациях, `--topbar-h` для закреплённых элементов, адаптивная шапка главы, оглавление главы одной прокручиваемой строкой на телефоне, перенос заголовков блоков кода, стили практики вынесены в компоненты `task-card`, `dom-lab`.
- **Учебный проект.** `HOST` (по умолчанию 127.0.0.1, в Compose 0.0.0.0), корректное чтение тела по байтам, README без отчёта и с контрактом API, `forbidOnly` в CI, `permissions` и таймаут в workflow, `engines`, скрипт `verify`.

## Реально выполненные проверки

Подробная таблица с границами проверок — в главе «О учебнике» внутри HTML. Все автоматические проверки лежат в `tools/` и запускаются командой `npm run check` (в CI — на каждый push).

- **Учебный проект.** `npm ci`, lint, typecheck, API-тест и 2 теста Playwright прошли локально (Node.js 22.22.0, Chromium 141) и на раннере GitHub Actions. Контролируемое падение (сумма × 1001) обнаружили API-тест и UI-тест; проверка автоматизирована (`npm run mutation`) и тоже выполнена в CI.
- **Docker Compose на реальном раннере GitHub Actions.** Первый прогон упал: `clean-results.mjs` пытался удалить подключённый том `allure-results` (EBUSY) — ошибка, которую локально, без Docker, найти было нельзя. После исправления: образ собирается, приложение проходит healthcheck, тесты в контейнере — `2 passed`, код возврата сервиса `tests` — 0.
- **Печать всего учебника.** Кнопка «Печать всего учебника» печатала одну главу из 40 (специфичность CSS: правило `.js .chapter:not(.print-on)` перебивало `body.print-all .chapter`). Исправлено; PDF — 532 страницы, `npm run pdf`.
- **Скриншоты.** Просмотрены все 40 глав: 1440 px (шапка и первый экран) и 390 px (середина главы — таблица, интерактив или выноска), по контактным листам.
- **Вёрстка.** 40 глав × 5 ширин (360, 390, 768, 1024, 1440 px) × 2 темы = 400 сочетаний без горизонтальной прокрутки и элементов за краем экрана (локально); в CI — 360, 768, 1440 px. Размер текста «Крупный» на 360 px — 7 страниц.
- **Интерактивы.** 31 интерактив, 446 проверок: крайние значения, все кнопки, сброс — без ошибок JavaScript, `NaN` и `Infinity`.
- **Поведение.** 22 проверки: поиск, клавиши в полях ввода, подсказка термина с клавиатуры, `Esc`, мобильное меню, фон меню при прокрутке, сохранение темы, режима и прогресса, офлайн, без `localStorage`, повреждённые настройки, без JavaScript. Эти проверки нашли ошибку в моей же правке: после закрытия подсказки по `Esc` с фокусом внутри всплывающего окна возникало исключение; исправлено.
- **Ссылки и содержание.** 2007 внутренних ссылок без битых, 220 терминов глоссария, дублей `id` нет, меню совпадает со списком глав, архив проекта совпадает с `aqa-lab-starter/` и не содержит `node_modules` и секретов, версия Playwright в тексте совпадает с проектом.
- **Точность.** Таблица actionability сверяется с исходниками установленного `playwright-core` (`npm run check:actionability`; на версии 2 эта проверка падает, на версии 3 проходит). SQL главы выполнен на PostgreSQL 18.3 (PGlite), учебный движок MiniSQL сверен с ним (`npm run check:sql`). 9 JS-примеров дали заявленный вывод; 129 TypeScript-фрагментов проверены компилятором (разово, вручную).
- **Сами проверки** проверены на версии 2: статическая проверка находит 71 нарушение, проверка actionability — ошибку в таблице.

## Что исправлено по замечаниям после первой сдачи

- **Градиент бокового меню обрывался.** Градиент лежал на псевдоэлементе высотой в один экран внутри прокручиваемого меню, поэтому ниже первого экрана фон становился плоским. Теперь градиент задан на самом меню (тёмная и светлая темы, яркость фона учитывается).
- **Панель букв глоссария** на телефоне перекрывала текст полупрозрачным фоном и занимала пять строк — теперь сплошной фон, на телефоне не закрепляется.
- **Блоки «Кратко»**: не больше 6 правил и 5 терминов (было до 8 и 12); часть правил объединена, дубли с разделами убраны. Лимиты проверяет `check:static`.
- **Исходники.** `src/` (главы, CSS, JS, `book.json`, оболочка) и `tools/build.mjs`; сборка из `src/` совпадает с `AQA_Lab_v3.html`, это проверяется в CI. Оговорка: исходный генератор версии 2 в репозитории отсутствовал, `src/` получен разбором собранного файла.

## Оставшиеся ограничения

- Docker и CI проверены на одном раннере Linux. Docker Desktop (Windows, macOS), GitLab CI и workflow из архива проекта (`tests.yml`) не запускались.
- Проверялся только Chromium; Firefox, WebKit, реальные мобильные браузеры и просмотрщики локальных HTML — нет.
- Текст глав, не затронутый правками, перечитан выборочно (асинхронность, локаторы, assertions, fixtures, HTTP, SQL, часть окружения), а не целиком.
- Корректность моделей-интерактивов проверена чтением формул, не независимым пересчётом каждого сценария.
- Ссылки на внешнюю документацию не проверялись автоматически.
- Терминные подсказки в `src/chapters/` — готовая разметка; инструмента для их повторной автоматической расстановки в репозитории нет (скрипт переразметки лежит в архиве `tools/legacy-v2-to-v3/`).

## Предложения по дальнейшему развитию

Формат: проблема → изменение → польза → приоритет → сложность.

### Необходимо для следующей версии

1. Правки глав идут в готовую разметку со всеми подсказками → вынести тексты глав в источник без подсказок (Markdown/YAML) и расставлять термины генератором по `book.json` → правки без ручной работы с `<button class="term">` → высокий → высокая.
2. Сверка справочных таблиц покрывает только actionability → добавить сверку таймаутов по умолчанию (тест 30 с, expect 5 с) и списка встроенных фикстур с установленным Playwright → корректность при обновлениях → средний → низкая.
3. Проверка TypeScript-фрагментов глав была разовой → вынести её в `tools/checks` с белым списком ожидаемых ошибок «имя не найдено» → защита от неверных API → средний → средняя.
4. Docker и CI проверены на одном раннере Linux → запускать учебный проект без Docker на Linux, macOS и Windows в матрице CI → меньше сюрпризов для студентов → средний → низкая.

### Полезно при дальнейшем развитии

5. Лимиты «Кратко» проверяются, но актуальность по смыслу — нет → добавить в шаблон ревью пункт «изменённые утверждения сверены с блоком „Кратко“» → «Кратко» не расходится с главой → средний → низкая.
6. В расчётных интерактивах нет явной проверки модели → добавить небольшой «пример с числами» в подпись и тест на соответствие формулам → доверие к моделям → средний → средняя.
7. SQL Playground не поддерживает `GROUP BY` по номеру и оконные функции → реализовать или явно показывать понятное сообщение об ограничении → меньше сюрпризов → низкий → средняя.
8. Мобильное чтение таблиц — прокрутка внутри контейнера → подсветка «есть ещё колонки» → заметность прокрутки → низкий → низкая.

### Необязательные эксперименты

9. Тренажёр «найди ошибку в тесте» на базе реальных падений учебного проекта → связать «Первый запуск» с главами о диагностике → средний → высокая.
10. Версия для печати одним PDF с оглавлением → удобство офлайн-чтения → низкий → средняя.
