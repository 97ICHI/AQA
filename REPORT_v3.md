## Выполненные изменения

- **Содержание.** Переписаны введение и «Первый запуск» (теперь это короткий маршрут и один рабочий цикл с реальным выводом падения), «Кратко» для окружения, практики и «Первого запуска». Все 17 блоков версии 2 перенесены в логику глав (якоря сохранены), частично слиты с соседним текстом: Event Loop в Node.js, определение safe/idempotent, дубль детерминированности между главами 22 и 24. Сведения о версиях, истории, проверках, ограничениях и источниках собраны в новой справочной главе «О учебнике». Оглавления глав и ссылки «Кратко» пересобраны, «глава N» стали ссылками.
- **Подсказки.** 1430 → 760: один термин один раз в разделе, только в обычном тексте (не в коде, заголовках, таблицах-шапках, ссылках, на метках кода). Исправлены все найденные искажения регистра. Подсказка открывается с клавиатуры, фокус переходит внутрь, `Esc` возвращает его на термин.
- **Дизайн.** Единые токены радиусов (3 ступени), палитра разделов без жёлтого и зелёного, свечение отключено, спокойные линии вместо градиентных украшений, фиолетово-голубые акценты в светлой теме и в демонстрациях, `--topbar-h` для закреплённых элементов, адаптивная шапка главы, оглавление главы одной прокручиваемой строкой на телефоне, перенос заголовков блоков кода, стили практики вынесены в компоненты `task-card`, `dom-lab`.
- **Учебный проект.** `HOST` (по умолчанию 127.0.0.1, в Compose 0.0.0.0), корректное чтение тела по байтам, README без отчёта и с контрактом API, `forbidOnly` в CI, `permissions` и таймаут в workflow, `engines`, скрипт `verify`.

## Реально выполненные проверки

Подробная таблица с границами проверок — в главе «О учебнике» внутри HTML. Кратко:

- проект: `npm ci`, lint, typecheck, API-тест, 2 теста Playwright — зелёные (Node.js 22.22.0, Chromium 141); контролируемое падение (сумма × 1001) обнаружено API-тестом и UI-тестом, код восстановлен;
- встроенный архив распакован, совпадает с `aqa-lab-starter/`, `npm run verify` на распакованной копии зелёный;
- `docker compose config -q` и разбор YAML workflow — успешно; **сборка образа, запуск Compose и workflow не выполнялись**;
- 2007 внутренних ссылок без битых, 220 терминов глоссария открываются, дублей `id` нет;
- 40 глав × 5 ширин × 2 темы без горизонтальной прокрутки и элементов за краем экрана; размер текста «Крупный» на 360 px — 7 страниц;
- 31 интерактив: крайние значения, все кнопки, сброс — без ошибок и NaN; формулы расчётных моделей прочитаны и сверены с текстом;
- SQL главы выполнен на PostgreSQL 18.3 (PGlite); MiniSQL совпал на 40 из 43 запросов (расхождение — `GROUP BY` по номеру столбца);
- 9 JS-примеров дали заявленный вывод; 129 TS-фрагментов проверены компилятором; YAML/JSON разбираются;
- поиск, клавиши, подсказка с клавиатуры и касанием, `Esc`, мобильное меню, сохранение темы/режима/прогресса, офлайн, без `localStorage`, повреждённые настройки, без JavaScript, печать главы в PDF;
- просмотрены скриншоты: введение, «Первый запуск», «О учебнике», SQL, Assertions (тёмная и светлая темы, 390–1440 px).

## Оставшиеся ограничения

- Docker, Compose и GitHub Actions в этой среде не запускались.
- Проверялся только Chromium; Firefox, WebKit, реальные мобильные браузеры и просмотрщики локальных HTML — нет.
- Скриншоты просмотрены выборочно, не по всем 40 главам.
- Корректность моделей-интерактивов проверена чтением формул, не независимым пересчётом; текст глав, не затронутый правками, перечитан выборочно (асинхронность, локаторы, assertions, fixtures, HTTP, SQL, часть окружения), а не целиком.
- Ссылки на внешнюю документацию не проверялись (нет доступа в интернет).
- Печать всего учебника кнопкой настроек не прогонялась до PDF.

## Предложения по дальнейшему развитию

Формат: проблема → изменение → польза → приоритет → сложность.

### Необходимо для следующей версии

1. Нет автоматической защиты от регрессий текста и вёрстки → вынести проверки этой сборки (ссылки, переполнение, интерактивы, порча кода подсказками) в скрипт в репозитории и запускать при сборке → не повторятся ошибки версии 2 → высокий → средняя.
2. Исходники учебника (генератор) отсутствуют, правки идут по готовому HTML → вернуть источник глав в репозиторий и собирать HTML из него → безопасные правки и ревью диффов → высокий → высокая.
3. Docker и CI не проверены → прогнать `docker compose up` и workflow на реальной машине/в репозитории и зафиксировать результат в «О учебнике» → снимает главное ограничение → высокий → низкая.
4. Таблица actionability и похожие справочные таблицы переписаны вручную → сверять с `playwright-core` или документацией при каждом обновлении версии Playwright → корректность → средний → низкая.

### Полезно при дальнейшем развитии

5. Ответы «Кратко» длиннее, чем нужно для повторения в части глав → сократить до 4–5 правил и одной ошибки, держать формулы и команды → быстрее повторение → средний → средняя.
6. В расчётных интерактивах нет явной проверки модели → добавить небольшой «пример с числами» в подпись и тест на соответствие формулам → доверие к моделям → средний → средняя.
7. SQL Playground не поддерживает `GROUP BY` по номеру и оконные функции → реализовать или явно показывать понятное сообщение об ограничении → меньше сюрпризов → низкий → средняя.
8. Мобильное чтение таблиц — прокрутка внутри контейнера → подсветка «есть ещё колонки» → заметность прокрутки → низкий → низкая.

### Необязательные эксперименты

9. Тренажёр «найди ошибку в тесте» на базе реальных падений учебного проекта → связать «Первый запуск» с главами о диагностике → средний → высокая.
10. Версия для печати одним PDF с оглавлением → удобство офлайн-чтения → низкий → средняя.
